# フォローノート 公式案内サイト

日本語の公式案内・プライバシーポリシー・FAQです。HTMLとCSSのみで動作します。外部ライブラリ・外部フォント・広告・独自のアクセス解析はありません。

- `index.html`：トップ
- `privacy.html`：プライバシーポリシー
- `support.html`：ヘルプ・サポート
- `style.css`：共通スタイル

公開には専用リポジトリのSettings → Pages → Deploy from a branch → main / (root)を利用し、HTTPSを有効にします。
Flutterアプリのソース、認証情報、顧客情報、バックアップをこのリポジトリへ追加しないでください。
